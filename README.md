

# ispconfig-darkmode_theme
A refresh of the default theme for ISPConfig including dynamic darkmode toggle

## Install
To install, place the theme folder here:

```bash
/usr/local/ispconfig/interface/web/themes
```

You can either replace the folder "default" or choose different name
